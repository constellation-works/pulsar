usage: pulsar history [-h] [--format MODE] [--json] [--account ACCOUNT] [--limit LIMIT]

the newest ledger rows (offline)

options:
  -h, --help         show this help message and exit
  --format MODE      output: auto (a table on a terminal, tab-separated lines when piped), table
                     or json; default: $PULSAR_FORMAT, else auto
  --json             shorthand for --format json
  --account ACCOUNT  only this account's rows (an alias, provider:handle such as x:<handle>);
                     default: all
  --limit LIMIT      rows to show, 1..100; default: 20
