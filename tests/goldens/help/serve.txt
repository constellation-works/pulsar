usage: pulsar serve [-h] [--format MODE] [--json] [--transport {stdio,http}]
                    [--host {127.0.0.1,localhost,::1}] [--port PORT]

run the MCP server

options:
  -h, --help            show this help message and exit
  --format MODE         output: auto (a table on a terminal, tab-separated lines when piped),
                        table or json; default: $PULSAR_FORMAT, else auto
  --json                shorthand for --format json
  --transport {stdio,http}
                        stdio, or streamable HTTP on a loopback port; default: stdio
  --host {127.0.0.1,localhost,::1}
                        loopback address for --transport http; default: 127.0.0.1
  --port PORT           port for --transport http; default: 8977
