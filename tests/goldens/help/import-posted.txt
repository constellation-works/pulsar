usage: pulsar import-posted [-h] [--format MODE] [--json] [--account ACCOUNT] [--confirm] source

import a retired routine's posted.jsonl into the ledger (idempotent); reports only without --confirm

positional arguments:
  source             path to posted.jsonl

options:
  -h, --help         show this help message and exit
  --format MODE      output: auto (a table on a terminal, tab-separated lines when piped), table
                     or json; default: $PULSAR_FORMAT, else auto
  --json             shorthand for --format json
  --account ACCOUNT  the account those posts were made as; default: default_account in
                     config.toml, else the only bound account
  --confirm          actually write the rows
