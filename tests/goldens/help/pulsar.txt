usage: pulsar [OPTIONS] COMMAND ...

Social write connector for the constellation: publish to X as accounts
a human bound on this host, through one ledger and policy.

Accounts:
  auth           bind, check and log out the accounts on this host

Publish:
  validate       check a plan offline: per account, what would post, its digest and cost
  publish        publish a plan through the ledger and policy; validates only without --confirm
  reconcile      settle writes whose outcome is unknown from the account's timeline (reads X only
                 when something is unresolved)

Observe:
  status         budgets, today's posts, quiet hours and unresolved writes (offline)
  history        the newest ledger rows (offline)

Maintenance:
  import-posted  import a retired routine's posted.jsonl into the ledger (idempotent); reports
                 only without --confirm
  migrate        upgrade the home in place: the ledger schema, then phase 1 credentials; reports
                 only without --confirm

Services:
  serve          run the MCP server
  orbit-tool     answer one Orbit plugin request (envelope on stdin, response on stdout)

Options:
  -h, --help     show this help message and exit
  --format MODE  output: auto (a table on a terminal, tab-separated lines when piped), table or
                 json; default: $PULSAR_FORMAT, else auto
  --json         shorthand for --format json
  -V, --version  show program's version number and exit

Exit codes: 0 ok, 1 failed or not settled, 2 usage error.
Run `pulsar COMMAND --help` for a command's own options and examples.
