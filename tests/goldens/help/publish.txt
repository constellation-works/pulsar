usage: pulsar publish [-h] [--format MODE] [--json] [--account ACCOUNT]
                      [--idempotency-key IDEMPOTENCY_KEY] [--caller CALLER] [--confirm]
                      plan

publish a plan through the ledger and policy; validates only without --confirm

positional arguments:
  plan                  plan file (YAML)

options:
  -h, --help            show this help message and exit
  --format MODE         output: auto (a table on a terminal, tab-separated lines when piped),
                        table or json; default: $PULSAR_FORMAT, else auto
  --json                shorthand for --format json
  --account ACCOUNT     one of the plan's accounts, or the one to bind a plan that names none;
                        default: default_account in config.toml, else the only bound account
  --idempotency-key IDEMPOTENCY_KEY
                        the write's key: re-running with it replays the receipt instead of posting
                        again; default: derived from the plan's digest and the account
  --caller CALLER       audit label recorded in the ledger; default: $PULSAR_CALLER, else pulsar-
                        cli
  --confirm             actually publish (costs money)

Examples:
  pulsar publish plan.yaml            # what would post, and its cost
  pulsar publish plan.yaml --confirm  # post it (re-running replays the receipt)
