usage: pulsar auth logout [-h] [--format MODE] [--json] [--account ACCOUNT] [--confirm]

delete an account's tokens (the account is kept as revoked); needs --confirm

options:
  -h, --help         show this help message and exit
  --format MODE      output: auto (a table on a terminal, tab-separated lines when piped), table
                     or json; default: $PULSAR_FORMAT, else auto
  --json             shorthand for --format json
  --account ACCOUNT  the account to log out; default: default_account in config.toml, else the
                     only bound account
  --confirm          actually delete the tokens
