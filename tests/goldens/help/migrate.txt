usage: pulsar migrate [-h] [--format MODE] [--json] [--confirm]

upgrade the home in place: the ledger schema, then phase 1 credentials; reports only without --confirm

options:
  -h, --help     show this help message and exit
  --format MODE  output: auto (a table on a terminal, tab-separated lines when piped), table or
                 json; default: $PULSAR_FORMAT, else auto
  --json         shorthand for --format json
  --confirm      actually upgrade the home

An upgraded ledger is refused by older pulsar versions; moved credentials stay moved.
