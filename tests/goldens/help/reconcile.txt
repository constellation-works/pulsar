usage: pulsar reconcile [-h] [--format MODE] [--json] [--account ACCOUNT]

settle writes whose outcome is unknown from the account's timeline (reads X only when something is unresolved)

options:
  -h, --help         show this help message and exit
  --format MODE      output: auto (a table on a terminal, tab-separated lines when piped), table
                     or json; default: $PULSAR_FORMAT, else auto
  --json             shorthand for --format json
  --account ACCOUNT  the account to reconcile; default: default_account in config.toml, else the
                     only bound account

Exit 0 only when every row it looked at is settled.
